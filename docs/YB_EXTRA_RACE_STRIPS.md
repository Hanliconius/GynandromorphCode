# Existing additional race strips

The --add-race-strips option adds H. melpomene amaryllis (ERR2298257, ERR2298260; Yb+), H. timareta thelxinoe (ERR2298263, ERR2298265; Yb+) and H. timareta florencia (ERR2298235, ERR2298236; Yb-), using the existing overlay run's BAM manifest. These are paper-assigned yellow-bar phenotypes; they do not establish allele dosage or independently resolved dorsal/ventral state.

No SNP reselection, new downloads or alignments are performed. On each reference and interval, use the same already-selected SNPs and allele orientation as the corrected focal display. Count fragments with the existing MAPQ30/baseQ30 observation helper, counting overlapping mates once. An individual's displayed frequency is rosina-associated count divided by the two selected allele counts, requiring >=8 such observations. Other bases are retained in the output but excluded from that denominator. The race strip is an unweighted mean over callable individuals, so the number contributing per site can be one or two, and sites with neither are missing. Individual count/frequency TSVs allow this to be audited. These are measured read frequencies, not posterior genotype doses or chromosome-frequency estimates.

Original rosina/melpomene rows and posterior95 merged Left/Right genotypes are unchanged. The same optix palette is used. The additional races were not used for marker selection. Their displayed frequencies are descriptive; the strict original selection still conditions the site set on rosina versus melpomene. The output is a new four-page timestamped PDF Yb_d_v_posterior95_corrected_genotypes_extra_race_strips.pdf. BAM paths and sample/race identities are recorded in audit.json. This extension is separate from pending extra controls, PK alignments, and future broader SNP selection.

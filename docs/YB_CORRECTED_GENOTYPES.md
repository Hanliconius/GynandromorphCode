# Yb corrected genotype display

Implemented after archiving the unchanged original caller at commit 89640c6. The adapter imports its state_log_likelihoods function; it does not replace the original caller or rerun its main function. That likelihood uses nine diploid L/R states, reciprocal contamination, sequencing error, ALT log-odds mapping bias and beta-binomial concentration. Original posterior inference uses equal state priors, so posterior is softmax of the nine log likelihoods.

This first Yb implementation reads all five nuisance parameters from the saved optix mixture summary, without rounding or refitting. The supplied summary has cLeft=0.2086930887, cRight=0.2098653549, error=0.0005, ALT bias=-0.1195160302 and concentration=56.99495196. This is an explicitly labelled transfer of the optix fit to Yb on each reference, not a new Yb fit or a reuse of approximately 18% genome-wide parameters. Reference-specific mapping bias may differ; compare both assemblies and interpret that limitation.

Inputs are the four existing Yb interval SNP-count TSVs. SNP selection remains based on the original two rosina and two melpomene controls, independently of focal differences. T2 and T3 counts are summed within each side, matching the merged-side structure of the optix display. Counts are MAPQ30/baseQ30 fragment observations with overlapping mates counted once; these differ from the original caller's VCF AD inputs. Thus this reuses the likelihood and fit, not the original complete upstream calling pipeline. Other bases remain in the output but are excluded from the biallelic likelihood denominator. No focal GQ filter is imposed. Both merged sides require at least two biallelic observations.

Each SNP's REF nucleotide is read from the matching prepared reference FASTA. If REF matches neither control-associated nucleotide, exclude and audit that SNP. Otherwise construct REF/ALT counts before applying the original ALT-bias function. Convert accepted ALT genotype dosage into rosina-associated dosage only afterward. Equal priors are retained; no genotype states are excluded based on founder expectations. Accept the genotype pair only at posterior >=0.95; display both sides missing otherwise. Keep all nine state posteriors and count totals for review. Best-state GT columns below the threshold are diagnostics, not accepted calls.

The four-page vector PDF uses the optix palette (0 #D7EDF5, 0.5 #ECCB63, 1 #662A83, missing #C8C8C8). Control rows retain measured frequencies; focal rows contain only 0, 0.5, 1 or missing. Locus connections and legacy interval shading are retained, with a separate Luca primer anchor at Yb(d). Race association does not establish functional Yb genotype or phase, particularly at Yb(v).

Each execution creates a new timestamped corrected_genotypes directory without replacing earlier outputs. It copies the original caller, adapter and saved fit summary, hashes caller/summary/count inputs, and records parameters, panel call counts, reference inputs, aggregation and exclusions in audit.json. Reference FASTA paths are recorded; full FASTA hashes are not computed by this small reporting job. Existing exploratory continuous-frequency plots remain separate historical diagnostics.

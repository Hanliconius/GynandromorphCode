# All-sample Yb coverage

Yb_all_samples_coverage.py combines 21 PKs from the expanded dark/pale manifest, the original 10 race controls and four focal libraries, and four new rosina/melpomene individuals: 39 samples per reference, 78 profiles. The five original PKs are already part of the expanded manifest and are not added twice. PK grouping follows the manifest (12 dark, nine pale), not inferred Yb genotype. Dark/pale ivory phenotype is not interchangeable with dorsal/ventral yellow-bar status.

Reuse 28 arithmetic-mean profiles from yb_mixing_and_allele_evidence and 42 expanded PK coverage.tsv.gz profiles. Compute only eight missing profiles for ERR2298205, ERR2298206, ERR2298204 and ERR2298214 on the two references using the frozen mean_worker.py. Require completion markers and input profiles at submission. No downloads or alignments are submitted. Eight nano tasks (30 minutes each) produce these profiles, followed by a dependent nano report. If a task times out, reuse its completed outputs and retry that task on cpu; do not release the report with absent profiles.

Coverage is samtools depth -aa -s -q0 -Q30 -G1796: overlapping mates counted once, MAPQ30, baseQ0, flags1796 excluded. Supplementary reads are not separately excluded by this flag mask. Per bin use arithmetic mean in nonoverlapping 50bp bins, divided by each sample's full-Yb-contig mean including zeros. Original and expanded bin grids differ in their first bin; take exact common centres, checking unique indices and mean_depth/normalized_depth fields, without interpolation. Reference methods are kept separate.

Provide both own-contig normalized coverage and per-bin reference-matched control ratios. On Hmel2.5 the baseline is the mean of four melpomene normalized profiles; on HmRos it is four rosina. Baseline bins below 0.25 or nonfinite are masked, not divided. A baseline race's group mean is therefore 1 at retained bins, while individual curves still show variation. This is a mapping-response comparison, not absolute copy-number inference.

Plot seven control groups (rosina, melpomene, PK dark, PK pale, amaryllis, thelxinoe, florencia) as separate rows, each with faint individual curves, a thick group mean, and the four focal traces. Columns are full plotted range, legacy Yb(d) +/-1kb and legacy Yb(v) +/-1kb. Mark the Luca primer span separately. Axis range0–2 clips high and negative values visually; values remain in the exported table.

The eight-page PDF crosses two references, two scales and observed versus adjusted focal coverage. Adjustment transfers contamination fractions from the saved optix fit, without refitting: Ltrue=((1-cR)Lobs-cL Robs)/(1-cL-cR), Rtrue=((1-cL)Robs-cR Lobs)/(1-cL-cR). Apply inversion to linear own-contig-normalized mean profiles before baseline division. This assumes comparable mapping response and equal underlying contig dosage; transferred mixing parameters are not a separately fitted coverage model. No confidence intervals are claimed. All control curves remain observed. Negative adjusted values are exported without clipping.

Save run config, source paths, sample manifest, profile hashes, fit-summary hash/parameters, masked-bin counts, output tables and audit.json. The frozen mean worker also records BAM command and own-contig depth. Output goes into a new timestamped analysis/yb_all_samples_coverage directory. Previous plots are not replaced. Figure generation and analysis run only on Pegasus.

## Combined focal side display

At user request, focal curves are now combined Left and combined Right, with T2/T3 pooled before mixing inversion. For each library recover the full-contig mean from positive-bin mean_depth/normalized_depth ratios, requiring these ratios to be constant within relative tolerance1e-6. Compute each combined side profile as (T2 bin mean depth + T3 bin mean depth)/(T2 full-contig mean + T3 full-contig mean). This reproduces depth summation under the common bin grid and avoids giving unequal-depth libraries equal weight. It does not physically merge BAMs or re-mark duplicates across libraries. The original four library profiles remain inputs and are retained in exported tables; only the two combined traces appear on plots. Invert reciprocal mixing on the two combined linear normalized profiles, then divide by the reference-control baseline when requested. Record source libraries and denominators in the audit.
